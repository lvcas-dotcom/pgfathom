# 05 · Positioning & Metrics

← [Guide](../README.md)

Two questions every serious project has to answer honestly: **why this, and not something
that already exists**, and **does the published number mean what it looks like it means**.

| Page | Covers |
|---|---|
| [Prior art](prior-art.md) | Where `pgfathom` sits versus ORMs, data-profiling literature (SPIDER/BINDER/MIND/Metanome), Azimutt, Hackolade — and where it deliberately doesn't compete |
| [Measuring correctness](measuring-correctness.md) | The public benchmark corpus, the two measurement regimes, and the three things the recall table doesn't say |

## Why these two live together

Prior art without a number is marketing. A number without prior art doesn't say if it's
good. Both follow the same editorial principle as the rest of the project: **report what
underperforms with the same clarity as what works** — see the "join mining barely moves
the needle" section in [Measuring correctness](measuring-correctness.md).
